# 📊 Employee Salary Prediction

A Machine Learning project that predicts whether an employee earns **>50K or ≤50K** based on demographic and professional attributes.

---

## 🚀 Overview

This project applies **supervised machine learning** techniques to analyze employee data and classify salary levels. It demonstrates the full ML pipeline from data preprocessing to model evaluation.

---

## 🧠 Machine Learning Pipeline

- **Data Collection** – Dataset loaded and explored  
- **Data Cleaning** – Handling missing values and inconsistencies  
- **Feature Engineering** – Encoding categorical variables and scaling  
- **Model Training** – Training classification models  
- **Evaluation** – Measuring performance using metrics  
- **Prediction** – Final salary classification output  

---

## ⚙️ Tech Stack

- **Language:** Python  
- **Libraries:**  
  - Pandas  
  - NumPy  
  - Scikit-learn  
  - Matplotlib / Seaborn  

---

## 🔍 Features Used

- Age  
- Workclass  
- Education  
- Occupation  
- Hours-per-week  
- Gender  
- Native-country  
- And more  

---

## 📈 Model Evaluation

Common evaluation metrics used:

- Accuracy  
- Precision  
- Recall  
- F1 Score  
- Confusion Matrix  

---

## 📊 Output

The model predicts:

- `<=50K` → Low income  
- `>50K` → High income
